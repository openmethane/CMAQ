Stopped publishing the `ghcr.io/openmethane/cmaq` image; the last image is `1.0.2`. CMAQ is now published as two Debian 13 (trixie) packages attached to each GitHub release, `openmethane-cmaq` (MCIP, ICON and BCON) and `openmethane-cmaq-dev` (the I/O API, PARIO, STENEX, `bldmake` and `config.cmaq` that CMAQ-Adjoint builds against), together with a `SHA256SUMS` file, so install the packages from the release instead of using the image as a base.
